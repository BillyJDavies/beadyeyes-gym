# BeadyEyes Gym Tracker

BD IT Limited — Home Gym Training Plan & Session Tracker  
4-Day Upper/Lower Split · Sub-45 Minutes · Intermediate

---

## Files

- `index.html` — the app
- `manifest.json` — PWA manifest
- `sw.js` — service worker (offline support)
- `icon-192.png` — app icon (home screen)
- `icon-512.png` — app icon (splash screen)

---

## Deploying to GitHub Pages

1. Go to github.com and create a new repository called `beadyeyes-gym`
2. Upload all files in this folder to the repository root
3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Set branch to `main`, folder to `/ (root)`, click Save
6. After ~60 seconds your app will be live at:  
   `https://YOUR-USERNAME.github.io/beadyeyes-gym`

---

## Installing to your phone

### iPhone (Safari)
1. Open your GitHub Pages URL in Safari
2. Tap the **Share** button (box with arrow pointing up)
3. Scroll down and tap **Add to Home Screen**
4. Tap **Add** — the BeadyEyes icon will appear on your home screen

### Android (Chrome)
1. Open your GitHub Pages URL in Chrome
2. Tap the **three-dot menu** (top right)
3. Tap **Add to Home screen**
4. Tap **Add** — the BeadyEyes icon will appear on your home screen

Once installed it works fully offline — no internet connection needed during training.
